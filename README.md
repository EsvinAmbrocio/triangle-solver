# Herramientas de Precálculo

Aplicación universitaria creada con Vue 3 y Vite.

## Módulos

- Resolución de triángulos SSS, SAS, ASA/AAS y SSA.
- Análisis de polinomios de grado 2 a 5 con aritmética racional exacta.
- Teorema de ceros racionales y división sintética.
- Resolución de factores cuadráticos reales y complejos.
- Gráfica de polinomios con JSXGraph.
- Conversión entre grados decimales y radianes.

## Ejecución

Requiere Node.js 20.19 o superior.

```bash
npm install
npm run dev
```

Abrir `http://localhost:5173/` en el navegador.

## GitHub Pages

Cada push a `main` ejecuta las pruebas y publica automáticamente mediante GitHub Actions.

## Verificación

```bash
npm run test:run
npm run build
```
